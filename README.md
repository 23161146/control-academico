## Descripción del proyecto
Este proyecto consiste en una aplicación web desarrollada con React y Vite para consultar y administrar información de estudiantes. Incluye una pantalla de inicio de sesión, una tabla con los datos de los alumnos, opciones de búsqueda y filtrado, paginación y operaciones para gestionar los registros.

La aplicación obtiene los datos de estudiantes mediante una API externa y presenta información como nombre, apellidos, correo electrónico, dirección IP, carrera y semestre.

## API utilizada
Se eligió **Mockaroo** para proporcionar los datos de la tabla de estudiantes.

- **Endpoint:** `https://my.api.mockaroo.com/alumnos.json`
- **Formato de respuesta:** JSON
- **Datos:** identificador, nombre, apellidos, correo electrónico, dirección IP, carrera y semestre.
