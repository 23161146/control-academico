## Cómo ejecutar el proyecto

```bash
npm install      # también después de cada git pull (node_modules no se sube al repo)
npm run dev
```

Login de prueba (DummyJSON): usuario `emilys`, contraseña `emilyspass`.

Para usar Mockaroo en lugar de los datos locales, copia `.env.example` como `.env` y escribe la URL en `VITE_API_URL`.
